How repeatable is your agent?

One passing run says the agent can do a task. Repeated runs say whether it does it every time. Load a suite of repeated runs and AgentDiff computes pass^k with its interval, finds the flaky tasks, and shows how much the same task varies from run to run. It runs here, in your browser, as Python compiled to WebAssembly. Nothing you load is uploaded.

Headline figures

pass^k: passing every one of k tries

The mean over tasks of C(c,k)/C(n,k), with its 95% interval. A line that falls with k is an agent that can do the work but not every time.

Spread: tokens per run, against each task's median

Each dot is one run. At 1.0 a run used its task's median tokens; a wide row is a task that costs something different every time.

Every run, task by task

✓ passed, ✗ failed, in run order. A task with both is flaky: the place to look first. A task that passed every run still has a bound: how often it could fail, given how few runs there are.
